About This Tool

This tool was built as part of my Part II Dissertation: Mind the App: Detecting Dual-Use Applications.

It performs static analysis on uploaded Android APK files using Androguard, extracts a set of features (permissions, no. of hardcoded URLs etc) and then passes those features into a pre-trained machine learning model to produce a risk score.

How to use it
  1. Put your trained .pkl model files into the folder your .env file points to.
  2. Make sure suspicious_permissions.json is in the location specified in your .env file.
  3. Upload an APK and pick a model
  4. Wait for the analysis to finish (big apps can take a few minutes)
Models Available
  • random_forest_model.pkl — Random Forest classifier
  • logistic_model.pkl — Logistic Regression
  • svm_model.pkl — Support Vector Machine
  • gradient_boosting_model.pkl — Gradient Boosting
  • consensus_model.pkl — Ensemble
