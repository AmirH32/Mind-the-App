About This Tool

This tool was developed for my Part II Dissertation project: Mind the App: Detecting Dual-Use Applications.

The system performs static analysis on uploaded Android APK files. It uses Androguard to perform static analysis, gathers a number of features such as permissions, URLs and metadata, and then passes these values into the user-selected trained machine learning model.

The final output is a predicted risk score intended to help identify potentially suspicious applications.

How To Use
  1. Place trained model .pkl files in the model folder that your src/web_app/utils/.env file points to.
  2. Ensure there is a suspicious_permissions.json in the location specified by your .env file.
  3. Upload an APK file.
  4. Select one available model.
  5. Wait for processing to complete.
Example Models
  • random_forest_model.pkl - Random Forest
  • logistic_model.pkl - Logistic Regression
  • svm_model.pkl - Support Vector Machine
  • gradient_boosting_model.pkl - Gradient Boosting
  • consensus_hard_model.pkl - Ensemble Voting (discrete output)
  • consensus_soft_model.pkl - Ensemble Voting (probabilistic output)
